# Malleus Anki Helper Add-on

The Malleus add-on integrates Anki with the Malleus Notion databases so you can **search across all of the Malleus databases at once, find existing cards with matching tags, and create new cards with proper tagging** — without leaving Anki.

[:material-download: Install the add-on](installation.md){ .md-button .md-button--primary }
[:material-youtube: Watch the how-to playlist](https://www.youtube.com/playlist?list=PLKoggb5cOb9lP5mCR2-2yqdFRe6aaqEaw){ .md-button }

## Features

- **Unified search** — a single search surfaces the best matches from every database: Subjects, Pharmacology, eTG, Rotation, Textbooks and Guidelines
- **Filter chips** — narrow results to specific databases with per-database toggles
- **Automatic tagging** — tags (including subtags and yield levels) are applied automatically when you create cards
- **Find existing cards** — jump straight to cards in your collection with matching tags
- **Editor integration** — open the page selector from the Add Cards dialog, the Browser toolbar, or a keyboard shortcut (++ctrl+alt+m++ by default)
- **Self-updating cache** — a local cache of the databases stays in sync with the daily Notion rebuild, checking conditionally so updates are cheap
- **Randomised card elements** — insert random numbers, image sequences and score calculations so cards can't be pattern-matched (see the [Randomisation guide](../note-type/features/randomisation.md))
- **Synced fields support** — offers shared [Synced Extra](../contributing/guidelines/synced-fields.md) content automatically when creating or re-tagging cards
