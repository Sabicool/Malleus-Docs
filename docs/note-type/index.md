# The Malleus Note Type

Every Malleus card uses the **MalleusCM - Cloze** note type — a custom cloze note type built for the deck. It ships with the deck automatically; there's nothing to install. This section covers what it does and how to make it yours.

## Highlights

- **Malleus colour theme** with full light and night mode support
- **[One-by-one clozes](features/index.md#one-by-one-clozes)** — reveal multiple answers in sequence, by button, keyboard or swipe
- **[Extra resource buttons](features/index.md#extra-resource-buttons)** — collapsible panels for AMBOSS, Oxford Handbooks, First Aid, eTG Complete, Talley & O'Connor and other linked resources, so the card stays clean
- **Personal Notes and Missed Questions fields** — your own protected content, visually separated from deck content
- **[Randomised card elements](features/randomisation.md)** — numbers, lists and score calculations that change on every review, so you can't pattern-match the answer
- **[Colour-coded tags](features/index.md#tags)** — toggle with ++c++
- **Sanitised, responsive tables** that stay readable on mobile
- **[Image handling](features/images.md)** — double-click to enlarge, blur-to-reveal

The note type lives in its own repository: [Sabicool/Malleus-Note-Type](https://github.com/Sabicool/Malleus-Note-Type).
