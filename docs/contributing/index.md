# Contributing

Anyone can suggest new cards or improvements to existing ones — that's what keeps the deck alive. Before submitting, read the [Submission Guidelines](guidelines/index.md) once, then use the [Card Submission Checklist](checklist.md) each time you submit.

Suggestions go through **AnkiCollab**, so you need to be signed in to it (**AnkiCollab → Login**). The AnkiCollab buttons below only appear while you're signed in.

## Suggesting a new card

1. **Write it** — click **Add** (shortcut: ++a++). Set the deck to **Malleus Clinical Medicine** (or one of its subdecks) and the note type to the Malleus note type, whose name starts with **MalleusCM - Cloze**. AnkiCollab can only suggest cards in the Malleus deck with that note type. Creating the card from the [Malleus add-on](../addon/usage.md#creating-new-cards) sets both for you. Add cloze deletions with ++ctrl+shift+c++ / ++cmd+shift+c++.
2. **Reference it** — fill the Source field with an accepted source, URL, and access date (see [Referencing](guidelines/referencing.md)).
3. **Tag it** — at minimum one Subject tag, one Rotation tag, and a Yield tag. The [Malleus Helper add-on](../addon/index.md) does this for you (see [Tagging](guidelines/tagging.md)). Untagged cards are usually rejected.
4. **Submit it** — tick **Suggest on AnkiCollab** at the bottom of the Add window before you click **Add**, and the card is suggested as soon as it's added. To suggest cards you've already made, select them in the Browser, right-click → **AnkiCollab: Bulk suggest notes**.
5. **Explain it** — for a bulk suggestion, AnkiCollab asks *What type of change is this?* Pick one and add one or two sentences on why the cards should be accepted.

!!! tip "Switched from AnkiHub?"
    You'll have two Malleus note types. Use the one AnkiCollab installed (e.g. *MalleusCM - Cloze (AnkiCollab)*), not the old *… / Stapedius* one from AnkiHub, which can't be suggested. The Malleus add-on picks AnkiCollab's for you.

The maintainer team reviews every suggestion on AnkiCollab. To see where yours is up to, or any comments on it, open the card and click **AC: ↗ Open** to see it on the AnkiCollab website.

## Suggesting an edit

Spotted an error or a card that could be better? Press ++e++ during a review (or edit in the Browser), make your change, then click **AC: Suggest changes**. Pick the type of change, add a brief rationale, and submit. The same review process applies.

## Suggesting a card be removed

Duplicate or outdated card? Select it in the Browser, right-click → **AnkiCollab: Request note removal**.
