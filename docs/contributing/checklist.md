# Card Submission Checklist

!!! tip
    Run through this before you click **Suggest**. Each item links to the relevant section of the [Submission Guidelines](guidelines/index.md) if you need detail. First submission? Read the guidelines in full once first.

## Setup

- [ ] Deck is set to **Malleus Clinical Medicine**
- [ ] Note type is **MalleusCM - Cloze** — other note types can't be submitted

## Content

- [ ] The card is **clinically relevant** — not preclinical minutiae ([guidelines](guidelines/scope.md#keep-it-clinical))
- [ ] The topic **isn't already covered** — searched the Browser, the Helper add-on, and the project board ([guidelines](guidelines/scope.md#check-it-doesnt-already-exist))
- [ ] The card tests **one fact or concept**, with just enough cue to answer it ([guidelines](guidelines/scope.md#test-understanding-not-memorisation))
- [ ] Wording is **precise** — e.g. 'dysgeusia', not 'altered taste sensation'

## Structure

- [ ] Written as a **question and answer**, with the answer cloze-deleted ([guidelines](guidelines/card-structure.md))
- [ ] If inline cloze: there's enough **context** to work out the answer — previewed the card to check
- [ ] Multiple answers: count stated in the question, all under the **same cloze number**
- [ ] One-by-one only used for mnemonics or ordered sequences

## Formatting

- [ ] Abbreviations: full name first, (abbreviation) in brackets — or it's on the [accepted list](https://www.notion.so/2595964e68a48170a1d9e33fbf98b4de)
- [ ] Drugs: **no doses, brand names or timings** in cloze answers (intern-charted exceptions aside); regimens joined with *AND* / *OR*, one per line ([guidelines](guidelines/style-guide.md#writing-about-drugs))
- [ ] **Bold** the topic, <u>underline</u> what's being asked, *italics* only for organisms
- [ ] Punctuation: no full stops on single sentences; capitals only for names and sentence starts
- [ ] Extra field: bullet list if two or more points; sentences capitalised
- [ ] Tables made with the [table add-on](https://ankiweb.net/shared/info/805891399) and tagged `#Malleus_CM::#Card_Feature::Table`

## Referencing

- [ ] At least one **accepted source** in the Source field, with a URL ([guidelines](guidelines/referencing.md#accepted-sources))
- [ ] Source includes a **last-updated and access date**
- [ ] **Nothing copied verbatim** from the source
- [ ] AMBOSS/PassMedicine investigation or management content checked against **local Australian guidelines**
- [ ] Images: licence-appropriate, credited (*italics, 10pt*), in the Text or Extra field only, JPEG, resized sensibly ([guidelines](guidelines/referencing.md#images-and-copyright))

## Tagging

- [ ] At least one **Subject** tag and one **Rotation** tag ([guidelines](guidelines/tagging.md#how-to-tag))
- [ ] Exactly one **Yield** tag (high / medium / low / beyond medical school)
- [ ] **Special tags** added if relevant — pharmacology (any drug card), eTG, OSCE, question banks… ([guidelines](guidelines/tagging.md#special-tags))
- [ ] Genuinely can't find a tag? Use `#Malleus_CM::#TO_BE_TAGGED`

## Submit 🥳

- [ ] Click **👑 Suggest a new note** — or select several cards, right-click → **AnkiHub: Bulk suggest notes**
- [ ] Add a brief **rationale** for why the card should be accepted

!!! success "That's it!"
    The maintainer team will review your submission and email you the outcome. Minor change requests appear as comments on [AnkiHub Community](https://community.ankihub.net/) — no email is sent for those, so check back.
