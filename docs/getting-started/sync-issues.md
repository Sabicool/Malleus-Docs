# Fixing Sync Issues

Occasionally deck updates go wrong: cards not updating, duplicate cards, or missing or out-of-order tags. Work through these in order; they fix the vast majority of problems:

1. **Update the deck** — **AnkiCollab → Update Decks** from the main screen
2. **Check you're signed in** — the **AnkiCollab** menu shows **Login** when you're signed out. AnkiCollab only updates the deck while you're signed in, so sign in if it does.
3. **Check Malleus isn't coming from two places** — if AnkiHub is still installed and updating Malleus too, the two clash. Open **Tools → Malleus Deck Setup (AnkiCollab)…** and it stops AnkiHub updating Malleus for you (see [Switching from AnkiHub](switch-from-ankihub.md)).
4. **Clear unused tags** — in the Browser, **Notes → Clear Unused Tags**
5. **Check the database** — **Tools → Check Database**, then **Check Media**, then **Empty Cards**
6. **Remove deleted notes** — when the maintainers remove notes from the deck, the next update shows **Notes Removed**. Click **Delete Notes** to remove them, or **Review in Browser** to look first and delete them from there.
